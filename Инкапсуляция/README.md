# Задача 1. 
## Публичные, защищённые и приватные атрибуты
Создайте класс User с тремя атрибутами: name (публичный), _email (защищённый), __password (приватный).
В __init__ задайте все три. Попробуйте обратиться к каждому атрибуту извне класса. 
Объясните, что произойдёт при обращении к __password и как Python реализует name mangling (_User__password).

# Задача 2. 
## Геттеры и сеттеры вручную
Создайте класс BankAccount с приватным атрибутом __balance. Напишите методы get_balance() и deposit(amount) и withdraw(amount).
В withdraw проверяйте, что сумма не превышает баланс, в deposit — что сумма положительная. 
Прямое изменение __balance извне должно быть невозможно.

# Задача 3.
## Декоратор @property
Перепишите задачу 2, заменив геттеры/сеттеры на @property. 
Свойство balance доступно только для чтения (только getter, без setter).
Добавьте свойство owner с геттером и сеттером, 
при этом сеттер не должен допускать пустую строку — при попытке присвоить пустое имя выбрасывайте ValueError.

# Задача 4. 
## Контроль типов и диапазонов через property
Создайте класс Temperature с приватным атрибутом __celsius. Реализуйте свойства celsius и fahrenheit — оба с геттером и сеттером. 
Установка через любое из них пересчитывает внутреннее значение. Добавьте валидацию: температура не может быть ниже -273.15 °C (абсолютный ноль). 
При нарушении — ValueError.

# Задача 5. 
## Инкапсуляция в связке классов
Создайте класс Order с приватным списком __items и приватным статусом __status (значения: "new", "paid", "shipped", "delivered"). 
Методы: add_item(item) — работает только в статусе "new", pay() — переводит из "new" в "paid", ship() — из "paid" в "shipped".
Прямое изменение статуса извне запрещено. Метод get_summary() возвращает копию списка товаров (не ссылку на оригинал).
