# Задача №1. Простое наследование
Создайте класс Animal с атрибутом name и методом speak(), возвращающим "...". 
Создайте классы Dog и Cat, которые наследуют Animal и переопределяют speak() — "Гав!" и "Мяу!" соответственно.


# Задача №2. Вызов родительского конструктора
Создайте класс Person с атрибутами name и age. Создайте класс Student, 
который добавляет атрибут university. Используйте super().__init__() для инициализации родительских полей.
 Добавьте метод info(), возвращающий строку вида "Иван, 20 лет, МГУ".


# Задача №3. Расширение методов
Класс Logger имеет метод log(message), который печатает сообщение. Создайте TimestampLogger, который вызывает родительский log(), но добавляет к сообщению текущее время.

# Задача №4. Цепочка наследования
Постройте цепочку: Vehicle → Car → ElectricCar. У Vehicle есть brand и speed. 
У Car добавляется fuel_type. У ElectricCar — battery_capacity. 
Каждый класс должен корректно вызывать конструктор родителя. Добавьте метод describe() на каждом уровне.

# Задача №5. Переопределение и полиморфизм
Создайте класс Shape с методом area(). 
Реализуйте наследников Rectangle, Circle и Triangle с собственными реализациями area().
 Напишите функцию total_area(shapes), принимающую список фигур и возвращающую суммарную площадь.
