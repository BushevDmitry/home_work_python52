# Задача 1. books (создание, вставка, фильтрация, сортировка)

Создайте таблицу books с полями:
id (целое, первичный ключ)
title (строка, не может быть пустой)
author (строка)
year (целое)
pages (целое)
Вставьте 5 книг с разными годами и количеством страниц.


# Задача 2. products

Цель: научиться защищать данные на уровне схемы и обрабатывать ошибки вставки.
Создайте таблицу products:
id (целое, PK)
name (строка, уникальная)
price (десятичное)
category (строка, по умолчанию 'Разное')
is_available (??-надо подумать)
