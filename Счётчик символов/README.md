# Описание задачи:
Напишите программу, которая подсчитывает количество символов в
строках, введённых пользователем, пока тот не введёт слово «стоп».
## Указания:
1. Программа должна запрашивать у пользователя строки с помощью prompt()
2. Для каждой введённой строки подсчитывайте количество символов (без учёта
пробелов).
3. Если пользователь вводит «стоп» (регистр не имеет значения), программа
должна завершить выполнение.
4. В конце выведите общее количество символов во всех строках.
Ожидаемый результат:
Пример входных данных:
Введите строку: Привет
Введите строку: Как дела?
Введите строку: стоп
Пример результата:
Критерии оценивания:
o 4 балла — корректность: программа корректно подсчитывает символы,
игнорируя пробелы, и останавливается при вводе слова «стоп».
o 4 балла — чистота кода: код должен быть структурирован, с комментариями, где
это необходимо.
o 4 балла — обработка ошибок: программа должна правильно обрабатывать
некорректные данные и быть устойчивой к вводу пустых строк.
Максимальный балл за задание — 12 баллов.
