# Задача 1. Приветствие
Напишите декоратор hello, который перед вызовом оборачиваемой функции печатает "Привет!", а после — "Пока!".

# Задача 2. Логирование вызова
Напишите декоратор log_call, который при каждом вызове функции выводит её имя и переданные аргументы.

# Задача 3. Замер времени
Напишите декоратор timer, который замеряет и печатает время выполнения функции в секундах.

# Задача 4. Счётчик вызовов
Напишите декоратор count_calls, который запоминает, сколько раз была вызвана функция, и хранит это число в атрибуте call_count.

# Задача 5. Кэширование результата
Напишите декоратор cache, который запоминает результат для уже встречавшихся аргументов и не вычисляет функцию повторно.

# Задача 6. Ограничение доступа
Напишите декоратор require_role(role), принимающий параметр — название роли. Если глобальная переменная current_role не совпадает с нужной, функция не выполняется и печатается 

# Задача 7. Повтор при ошибке
Напишите декоратор retry(n), который при возникновении исключения повторяет вызов функции до n раз. Если все попытки провалились — пробрасывает последнее исключение.

# Задача 8. Валидация типов
Напишите декоратор validate_types, который проверяет, что типы переданных аргументов совпадают с аннотациями функции. Если нет — выбрасывает TypeError.
