# Задача 1. 
## Деление счёта
Друзья ужинают в ресторане. Напишите функцию split_bill(total, people), которая делит общий счёт на количество людей. 
Если people == 0 — поймайте исключение ZeroDivisionError и верните сообщение "Нельзя делить на 0 друзей!". 
Если total или people не числа — поймайте TypeError.

# Задача 2. 
## Кот на клавиатуре
Пользователь вводит свой возраст, но кот прошёлся по клавиатуре и ввёл "мяу". 
Напишите программу, которая запрашивает возраст через input(), преобразует в int, 
а при ошибке ValueError просит ввести заново — и так до тех пор, пока не получит число.

# Задача 3.
## Файл-призрак
Напишите функцию read_config(path), которая открывает файл по указанному пути и возвращает его содержимое. 
Если файл не найден (FileNotFoundError) — верните строку "Конфиг не найден, используем настройки по умолчанию". 
Блок finally должен печатать "Попытка чтения завершена" в любом случае.

# Задача 4.
## Свой собственный провал
Создайте собственное исключение WeakPasswordError. Напишите функцию check_password(pwd), 
которая выбрасывает WeakPasswordError с поясняющим сообщением, если пароль короче 8 символов или не содержит цифр. 
Вызовите функцию и обработайте исключение.

# Задача 5.
## Матрёшка ошибок
Напишите функцию get_value(data, key, index), которая принимает словарь data, 
достаёт из него список по ключу key, а из списка — элемент по индексу index. 
Обработайте отдельно: KeyError (нет ключа), IndexError (индекс за пределами списка), TypeError (значение по ключу — не список).
Для каждого случая выведите понятное сообщение.
