##  MVC.
# Задача 1: Список задач (To-Do List)
Создайте приложение для управления списком задач по паттерну MVC. Model хранит задачи, View отображает список, Controller обрабатывает команды добавления, удаления и изменения статуса задач.
 
Требования:
-Добавление новой задачи с описанием
-Удаление задачи по индексу
-Отметка задачи как выполненной/невыполненной
-Просмотр всех задач с их статусами
-Сохранение задач в файл JSON

# Задача 2: Библиотечная система
Разработайте систему учёта книг в библиотеке. Model содержит данные о книгах (название, автор, год, наличие), View отображает информацию, Controller управляет операциями поиска, выдачи и возврата книг.

Требования:
-Добавление книги в каталог
-Поиск книги по названию или автору
-Выдача книги читателю (изменение статуса наличия)
-Возврат книги
-Вывод списка всех книг и доступных книг

Тесты.
Задача 1: Тестирование арифметических функций
Создайте модуль с функциями сложения, вычитания, умножения и деления. 
Напишите тесты для проверки корректности работы всех функций, включая граничные случаи (деление на ноль, работа с отрицательными числами).Что протестировать:

Обычные случаи для каждой операции
Деление на ноль (должно выбрасывать исключение)
Работу с отрицательными числами
Работу с нулём
Задача 2: Проверка строковых функций
Реализуйте функции для работы со строками: подсчёт гласных, проверка на палиндром, реверс строки. Напишите unit-тесты для каждой функции.Что протестировать:

Обычные строки
Пустые строки
Строки с пробелами и знаками препинания
Строки только из цифр
Строки с разным регистром

# Задача 3: Тестирование класса "Банковский счёт"
Создайте класс BankAccount с методами deposit(), withdraw(), get_balance(). Напишите тесты для проверки всех операций.Что протестировать:

Пополнение счёта
Снятие денег при достаточном балансе
Попытка снять больше, чем есть на счёте
Начальный баланс
Отрицательные суммы для пополнения/снятия
