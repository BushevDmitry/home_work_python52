# Задача 1 - Фабричный метод с параметрами
Создай систему генерации документов. Абстрактный класс Document с методами Open() и Close(). Конкретные классы: PdfDocument, WordDocument, HtmlDocument. Абстрактный класс Application содержит фабричный метод CreateDocument() и конкретный метод NewDocument(), который вызывает фабричный метод, добавляет документ во внутренний список и вызывает Open(). Реализуй три конкретных приложения. В Main создай одно приложение и вызови NewDocument() несколько раз.

# Задача 2 — Фабричный метод + полиморфное поведение
Создай игровую систему с врагами. Абстрактный класс Enemy с методами Attack() и GetHealth(). Конкретные враги: Goblin (здоровье 50, атака ближняя), Dragon (здоровье 200, атака огнём), Skeleton (здоровье 80, атака стрелами). Абстрактная фабрика EnemyFactory с методом CreateEnemy(). Напиши класс Spawner, который принимает EnemyFactory в конструкторе и имеет метод SpawnWave(int count) — возвращает массив врагов. В Main создай волну из 3 гоблинов и 2 драконов, выведи информацию о каждом.

# Задача 3 — Базовая
Есть существующий класс OldPrinter с методом PrintMessage(string text). Нужно адаптировать его к интерфейсу IModernPrinter с методом Print(string text). Напиши класс-адаптер PrinterAdapter, который реализует IModernPrinter и внутри делегирует вызов OldPrinter. В Main продемонстрируй использование.
