# Задача 1: Погодная станция
Создайте систему погодной станции, где:

WeatherStation — субъект, хранящий температуру, влажность и давление
CurrentConditionsDisplay, StatisticsDisplay, ForecastDisplay — наблюдатели, которые отображают разную информацию
При изменении погодных данных все наблюдатели автоматически получают обновления

Требования:

Реализуйте методы attach(), detach(), notify()
Каждый наблюдатель должен иметь метод update()
Добавьте возможность отписки наблюдателя

# Задача 2: Биржевой тикер
Разработайте систему отслеживания акций:

Stock — субъект с названием и текущей ценой акции
Investor и TradingBot — наблюдатели
При изменении цены акции все заинтересованные стороны получают уведомление
Investor выводит сообщение о новой цене
TradingBot принимает решение о покупке/продаже на основе порогового значения
