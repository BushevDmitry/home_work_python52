# Задача 2. 
## Цепочка из трёх классов
Что нужно сделать:
Создайте цепочку наследования из трёх классов: Animal → Pet → Dog.
Класс Animal принимает в __init__ аргумент species (вид животного) и сохраняет его. По умолчанию species="неизвестно".
Класс Pet наследуется от Animal. Его __init__ принимает name (кличка) и species. Он вызывает super().__init__(species), а затем сохраняет name.
Класс Dog наследуется от Pet. Его __init__ принимает name и breed (порода). Он вызывает super().__init__(name, species="собака") — то есть вид задаётся автоматически. 
Затем сохраняет breed. В классе Dog реализуйте метод describe(), который возвращает строку со всеми тремя атрибутами.

# Задача 3. 
## Банковский счёт
Что нужно сделать:
Создайте класс Account с __init__(self, owner, balance). Добавьте метод withdraw(amount), который уменьшает баланс. 
Если amount > balance, печатает "Недостаточно средств" и ничего не списывает. Иначе — уменьшает баланс и печатает "Списано <amount>. Баланс: <balance>".
Создайте класс SavingsAccount(Account). Его __init__ принимает owner, balance и min_balance (минимальный остаток). 
Он вызывает super().__init__(owner, balance), а затем сохраняет min_balance.
SavingsAccount переопределяет withdraw: перед списанием проверяет, что balance - amount >= min_balance. Если условие не выполнено — отказывает. 
Если выполнено — вызывает super().withdraw(amount), делегируя саму логику списания родителю.
